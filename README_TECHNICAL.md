# 🚀 FounderOS: Technical Specification & Architecture Manual

> **Mission**: To provide founders with brutally honest, data-driven forensic analysis of startup ideas, stripping away the "hopium" and exposing structural flaws before capital is deployed.

---

## 1. Executive Summary
FounderOS is a premium AI-powered forensic engine designed to evaluate startup viability. Unlike generic AI chat tools, FounderOS uses a **Multi-Agent Forensic Pipeline** that simulates a cynical venture committee. It cross-references startup ideas against a proprietary database of historical failures (post-mortems), market-specific constraints (especially for India Tier 1/2), and bottom-up unit economics.

## 2. Technology Stack
- **Framework**: [Next.js 14+](https://nextjs.org/) (App Router, Server Actions)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Custom Design System: "Dark Luxury" / Glassmorphism)

## 3. The Forensic Pipeline (8-Agent Architecture)
The core logic resides in `src/lib/analysis.ts`. Every idea is subjected to an 8-stage "Stress Test":

| Agent | Name | Responsibility |
| :--- | :--- | :--- |
| **Agent 1** | **Problem Clarifier** | Evaluates if the problem is a "Vitamin" or a "Painkiller". Applies HIPAA/Compliance checks. |
| **Agent 2** | **Research Agent** | Analyzes market maturity, timing signals, and ARPU benchmarks. |
| **Agent 3** | **Competitor Detector** | Identifies direct competitors and "Failed Startup Ghosts" (why predecessors died). |
| **Agent 4** | **Market Analyst** | Calculates TAM/SAM/SOM using bottom-up math and user-provided pricing inputs. |
| **Agent 5** | **Pain Evaluator** | Scores adoption barriers: Trust, Habit, and Price. |
| **Agent 6** | **Startup Scorer** | Weighted mathematical aggregation of all factors (Feasibility, Innovation, etc.). |
| **Agent 7** | **Critic Agent** | The "Prosecutor". Identifies the fatal flaw and the "Killer Question" for the founder. |
| **Agent 8** | **Synthesizer** | Consolidates all data into a structured JSON for the dashboard. |

### The "Cynical" Persona
The pipeline is governed by a `CYNICAL_ROLE` prompt, which forces the AI to look for reasons to *reject* the idea rather than praise it. This ensures "Zero Hopium" feedback.

## 4. Knowledge Base & Data Schema
The system is seeded with deep context (see `scripts/seed_database.ts`):
- **Startups Table**: Success/Failure data for 100+ high-profile startups (TinyOwl, Byju's, Zepto, etc.).
- **Failure Post-mortems**: Detailed analysis of primary failure reasons (Unit economics, Network effects, Platform risk).
- **India Market Insights**: Specific behavioral data for India Tier 1 vs Tier 2 (Pricing sensitivity, Trust patterns).
- **Market Size Data**: Pre-calculated CAGR and TAM data for major sectors (EdTech, FinTech, SaaS).

---

## 5. Key UI/UX Features
- **The "Flip" UI**: A transition from a luxury landing page to a data-intensive dashboard.
- **Forensic Radar**: A Recharts-powered radar visualization showing the idea's "DNA" across 6 axes.
- **The AI Advisor Orb**: A persistent, interactive agent (`AIAdvisorOrb.tsx`) that allows the user to drill down into the report using the context of the generated analysis.
- **PDF Generation**: Native client-side PDF export for sharing with investors/partners.
- **Stateful Resume**: Uses a polling queue system (`/api/check-queue`) to handle heavy analysis without timing out.

---

## 6. API Architecture
- `POST /api/analyze`: Initial trigger for the pipeline.
- `GET /api/check-queue`: Long-polling endpoint for progress tracking.
- `POST /api/capture-lead`: CRM integration for founder data.
- `POST /api/chat`: Context-aware chat with the generated report.

---

## 7. Strategic Moat
FounderOS's primary moat is its **Reflective Multi-Agent Logic**. Instead of a single LLM prompt, it chains 8 specialized agents, where each subsequent agent critiques the findings of the previous ones. This simulates the rigorous debate of a professional Investment Committee.
